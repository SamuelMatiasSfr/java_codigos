# Gestão de Biblioteca

Sistema para gerenciar publicações de diferentes tipos com suporte a arquivo e interface gráfica.

## Objetivos

- Praticar herança e polimorfismo com entidades de biblioteca
- Trabalhar com persistência em arquivo CSV
- Integrar regras de negócio com interface Swing

## Funcionalidades

- Gerencia publicações como filme, software e gravação
- Registra e lê dados em arquivo CSV
- Permite execução por classe principal ou interface gráfica

## Tecnologias usadas

- Java
- Java Swing
- CSV

## Como executar

1. Baixe o repositório em formato zip
2. Extraia o zip em uma pasta local
3. Abra a pasta 14-gestao-biblioteca no terminal ou IDE
4. Compile os arquivos Java:

```bash
javac *.java
```

5. Execute a versão de console:

```bash
java Principal
```

6. Ou execute a interface gráfica:

```bash
java MyJFrame
```
