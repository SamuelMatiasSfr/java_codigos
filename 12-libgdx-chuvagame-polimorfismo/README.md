# LibGDX Chuva Game com Polimorfismo

Jogo 2D com múltiplos objetos em queda, aplicando herança e polimorfismo no loop principal.

## Objetivos

- Praticar polimorfismo em um projeto de jogo
- Trabalhar com diferentes comportamentos em classes derivadas

## Funcionalidades

- Processar diferentes tipos de objetos em queda no mesmo fluxo
- Aplicar comportamentos distintos para cada tipo de objeto
- Manter controle de pontuação e colisões com o jogador

## Tecnologias Usadas

- Java
- LibGDX
- VS Code

## Como Executar

1. Baixe e extraia o arquivo `.zip` do repositório
2. Abra a pasta `12-libgdx-chuvagame-polimorfismo` em uma IDE Java
3. Garanta que as bibliotecas da pasta libs estejam configuradas no classpath do projeto
4. Execute a classe `DesktopStarter.java` no caminho `src/gpjecc/blogspot/com`
