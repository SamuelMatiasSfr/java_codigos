# LibGDX Chuva Game com Save

Versão do jogo de chuva com persistência de estado para continuar a partida.

## Objetivos

- Evoluir um jogo LibGDX com sistema de salvamento
- Praticar serialização e leitura de dados de jogo
- Manter estado entre diferentes execuções

## Funcionalidades

- Salvar informações de jogo como pontos e vidas
- Carregar progresso salvo ao iniciar
- Manter gameplay de coleta de gotas com pontuação

## Tecnologias Usadas

- Java
- LibGDX
- VS Code

## Como Executar

1. Baixe e extraia o arquivo `.zip` do repositório
2. Abra a pasta `07-libgdx-chuvagame-com-save` em uma IDE 
3. Garanta que as bibliotecas da pasta libs estejam configuradas no classpath do projeto
4. Execute a classe `DesktopStarter.java` no caminho `src/com/gpjecc/blogspot/chuvagame`
