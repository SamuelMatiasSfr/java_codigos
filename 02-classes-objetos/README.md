# Classes e Objetos

Projeto de introdução a Programação Orientada a Objetos com cadastro simples de alunos.

## Objetivos

- Praticar criação de classes com atributos e métodos
- Aplicar encapsulamento com getters e setters

## Funcionalidades

- Criar objetos de aluno com dados acadêmicos
- Validar senha com regras de tamanho
- Armazenar alunos em lista para manipulação

## Tecnologias usadas

- Java
- CSV

## Como executar

1. Baixe o repositório em formato zip
2. Extraia o zip em uma pasta local
3. Abra a pasta 02-classes-objetos no terminal ou IDE
4. Compile o arquivo principal:

```bash
javac ClassesObjetos.java
```

5. Execute o programa:

```bash
java ClassesObjetos
```
