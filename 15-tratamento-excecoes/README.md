# Tratamento de Exceções

Projeto com exemplos de exceções personalizadas e validações de regras de negócio.

## Objetivos

- Praticar criação de exceções customizadas
- Aplicar try/catch em fluxos de execução
- Validar condições de erro com mensagens claras

## Funcionalidades

- Valida operações financeiras com exceção específica
- Realiza divisão com regra para números pares
- Demonstra captura e tratamento de diferentes erros

## Tecnologias usadas

- Java
- Tratamento de exceções

## Como executar

1. Baixe o repositório em formato zip
2. Extraia o zip em uma pasta local
3. Abra a pasta 15-tratamento-excecoes no terminal ou IDE
4. Compile os arquivos Java:

```bash
javac *.java
```

5. Execute a classe principal:

```bash
java Main
```
