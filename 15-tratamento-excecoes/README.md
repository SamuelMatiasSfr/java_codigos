# Tratamento de Exceções

Projeto com exemplos de exceções personalizadas e validações de regras de negócio.

## Objetivos

- Praticar criação de exceções customizadas
- Aplicar try/catch em fluxos de execução
- Validar condições de erro com mensagens claras

## Funcionalidades

- Validar operações financeiras com exceção específica
- Realizar divisão com regra para números pares
- Demonstrar captura e tratamento de diferentes erros

## Tecnologias Usadas

- Java
- VS Code

## Como Executar

1. Baixe e extraia o arquivo `.zip` do repositório
2. Abra a pasta `15-tratamento-excecoes` no terminal ou IDE
3. Compile os arquivos Java:

```bash
javac *.java
```

4. Execute a classe principal:

```bash
java Main
```
