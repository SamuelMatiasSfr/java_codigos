# Java Swing

Conjunto de aplicações desktop com interface gráfica para praticar eventos e componentes Swing.

## Objetivos

- Praticar construção de interfaces gráficas em Java
- Trabalhar com eventos de botão e interação com usuário
- Integrar lógica de negócio com componentes visuais

## Funcionalidades

- Converter temperatura entre Celsius e Fahrenheit
- Executar jogo de adivinhação com dicas e contagem de tentativas
- Exibir mensagens e resultados em janela

## Tecnologias usadas

- Java
- Java Swing

## Como executar

1. Baixe o repositório em formato zip
2. Extraia o zip em uma pasta local.
3. Abra a pasta 10-java-swing no terminal ou IDE
4. Compile os arquivos Java:

```bash
javac *.java
```

5. Execute uma das aplicações:

```bash
java MyJFrame
```

ou

```bash
java JogoAdivinhaNumero
```
