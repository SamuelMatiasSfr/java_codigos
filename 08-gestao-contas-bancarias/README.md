# Gestão de Contas Bancárias

Sistema de gerenciamento de contas com leitura de dados em CSV e separação por tipo.

## Objetivos

- Aplicar o conceito de herança 
- Ler dados de arquivo para inicialização de objetos

## Funcionalidades

- Carregar contas do arquivo contas.csv
- Diferenciar contas comuns, especiais e poupança
- Exibir totais e listagens de contas por categoria

## Tecnologias usadas

- Java
- CSV

## Como executar

1. Baixe o repositório em formato zip
2. Extraia o zip em uma pasta local
3. Abra a pasta 08-gestao-contas-bancarias no terminal ou IDE
4. Compile os arquivos Java:

```bash
javac *.java
```

5. Execute a classe principal:

```bash
java Main
```
