# Coletor de Lixo Java

Jogo LibGDX com monitoramento de memória da JVM para estudar comportamento do coletor de lixo.

## Objetivos

- Praticar desenvolvimento de jogo com LibGDX
- Observar consumo de memória durante execução

## Funcionalidades

- Executar gameplay com objetos em queda e pontuação
- Exibir informações de memória da JVM em tempo de execução
- Permitir avaliar efeitos do coletor de lixo durante o jogo

## Tecnologias Usadas

- Java
- LibGDX
- JVM
- VS Code

## Como Executar

1. Baixe e extraia o arquivo `.zip` do repositório
2. Abra a pasta `16-coletor-lixo-java` em uma IDE Java
3. Garanta que as bibliotecas da pasta libs estejam configuradas no classpath do projeto
4. Execute a classe `DesktopStarter.java` no caminho `src/gpjecc/blogspot/com`
