# DAO Pessoa com Arquivo e Swing

Aplicação com padrão DAO e interface gráfica para gerenciar cadastro de pessoas em arquivo CSV.

## Objetivos

- Praticar padrão DAO com persistência em arquivo
- Desenvolver interface gráfica para operações de cadastro
- Separar camadas de dados e visualização

## Funcionalidades

- Implementar operações de cadastro de pessoa via DAO
- Persistir dados no arquivo tabela.csv
- Exibir e manipular dados em janela Swing

## Tecnologias usadas

- Java
- Java Swing
- CSV
- Padrão de Projeto DAO

## Como executar

1. Baixe o repositório em formato zip
2. Extraia o zip em uma pasta local
3. Abra a pasta 22-dao-pessoa-arquivo-swing no terminal ou IDE
4. Compile os arquivos Java:

```bash
javac *.java
```

5. Execute a interface gráfica:

```bash
java TabelaGUI
```
