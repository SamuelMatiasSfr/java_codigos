# POO com Herança de Veículos

Projeto orientado a objetos com hierarquia de veículos para praticar herança e validações.

## Objetivos

- Aplicar herança em classes de domínio de veículos
- Reutilizar atributos e comportamentos em subclasses

## Funcionalidades

- Define classe base para móveis e veículos
- Implementa especializações como esportivo e carga
- Executa cenários de teste nas classes de questões

## Tecnologias usadas

- Java

## Como executar

1. Baixe o repositório em formato zip
2. Extraia o zip em uma pasta local
3. Abra a pasta 24-poo-heranca-veiculos no terminal ou IDE
4. Compile os arquivos Java:

```bash
javac *.java
```

5. Execute um dos cenários de teste:

```bash
java Questao2
```

ou

```bash
java Questao3
```
