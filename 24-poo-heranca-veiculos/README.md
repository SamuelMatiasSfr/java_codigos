# POO com Herança de Veículos

Projeto orientado a objetos com hierarquia de veículos para praticar herança e validações.

## Objetivos

- Aplicar herança em classes de domínio de veículos
- Reutilizar atributos e comportamentos em subclasses

## Funcionalidades

- Definir classe base para móveis e veículos
- Implementar especializações como esportivo e carga
- Executar cenários de teste nas classes de questões

## Tecnologias Usadas

- Java
- VS Code

## Como Executar

1. Baixe e extraia o arquivo `.zip` do repositório
2. Abra a pasta `24-poo-heranca-veiculos` no terminal ou IDE
3. Compile os arquivos Java:

```bash
javac *.java
```

4. Execute um dos cenários de teste:

```bash
java Questao2
```

ou

```bash
java Questao3
```
