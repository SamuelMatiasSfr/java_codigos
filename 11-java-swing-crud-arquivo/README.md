# Java Swing CRUD com Arquivo

Aplicação Swing para cadastro de registros com operações CRUD e persistência em CSV.

## Objetivos

- Praticar CRUD em interface gráfica
- Organizar operações de criação, leitura, atualização e exclusão

## Funcionalidades

- Cadastrar registros com campos de identificação
- Permitir consultar, editar e remover dados pela interface
- Salvar e recarregar dados do arquivo dados.csv

## Tecnologias Usadas

- Java
- Java Swing
- VS Code

## Como Executar

1. Baixe e extraia o arquivo `.zip` do repositório
2. Abra a pasta `11-java-swing-crud-arquivo` no terminal ou IDE
3. Compile o arquivo principal:

```bash
javac MyJFrame.java
```

4. Execute a aplicação:

```bash
java MyJFrame
```
