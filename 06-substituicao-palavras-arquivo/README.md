# Substituição de Palavras em Arquivo

Ferramenta de console para pesquisar e substituir palavras em arquivos de texto.

## Objetivos

- Praticar leitura e escrita de arquivos em Java
- Manipular strings em conteúdo textual
- Trabalhar com processamento de linhas em arquivos

## Funcionalidades

- Pesquisa uma palavra e informa linhas de ocorrência
- Substitui termos no texto e grava resultado em arquivo auxiliar
- Processa arquivos informados por parâmetro ou via console

## Tecnologias usadas

- Java

## Como executar

1. Baixe o repositório em formato zip
2. Extraia o zip em uma pasta local
3. Abra a pasta 06-substituicao-palavras-arquivo no terminal ou IDE
4. Compile os arquivos Java:

```bash
javac PesquisaArquivo.java SubstituiPalavra.java
```

5. Execute a busca:

```bash
java PesquisaArquivo
```

6. Execute a substituição:

```bash
java SubstituiPalavra
```
