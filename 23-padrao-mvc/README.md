# Padrão MVC

Projeto para organizar uma aplicação Java nas camadas Model, View e Controller.

## Objetivos

- Aplicar o padrão arquitetural MVC
- Separar responsabilidades entre dados, interface e controle

## Funcionalidades

- Representar dados de aluno no Model
- Exibir e receber dados na View em interface gráfica
- Coordenar ações no Controller entre model e view
- Inicializar o fluxo completo MVC na classe de teste

## Tecnologias Usadas

- Java
- Java Swing
- Padrão de Projeto MVC
- VS Code

## Como Executar

1. Baixe e extraia o arquivo `.zip` do repositório  
2. Abra a pasta `23-padrao-mvc` no terminal ou em uma IDE Java  
3. Compile os arquivos Java:

```bash
javac src/*.java
```

4. Execute a classe principal:


```bash
java src.TesteMVC
```
