# POO com Polimorfismo

Projeto para demonstrar polimorfismo com classes de mamíferos e chamada dinâmica de métodos.

## Objetivos

- Aplicar herança e sobrescrita de métodos
- Demonstrar polimorfismo com coleção de objetos
- Praticar organização de classes em pacote

## Funcionalidades

- Criar diferentes mamíferos em uma mesma lista
- Executar métodos comuns com comportamento específico por tipo
- Simular cenário de zoológico com interação entre objetos

## Tecnologias usadas

- Java

## Como executar

1. Baixe o repositório em formato zip
2. Extraia o zip em uma pasta local
3. Abra a pasta 13-poo-polimorfismo no terminal ou IDE
4. Compile os arquivos Java gerando os pacotes:

```bash
javac -d . *.java
```

5. Execute a classe principal:

```bash
java br.com.alissonrs.polimorfismo.Zoologico
```
