# Códigos em Java

Estes projetos foram desenvolvidos como atividades práticas da matéria Linguagem e Técnicas de Programação II no curso técnico de informática do CEFET-MG.

## Objetivos

- Praticar lógica de programação
- Praticar desenvolvimento backend com Java
- Aprender os fundamentos do Java
- Aplicar conceitos de POO como herança, polimorfismo e interfaces
- Trabalhar com persistência em arquivos e integração com banco de dados MySQL via JDBC
- Explorar sistemas distribuídos com Java RMI
- Exercitar padrões de projeto, como Singleton, Proxy, DAO e MVC
- Desenvolver tratamento de exceções e boas práticas de organização de código

## Tecnologias Usadas

- Java
- Java Swing
- Java RMI
- JDBC
- SQL
- MySQL
- LibGDX
- Padrões de Projeto (Singleton, Proxy, DAO, MVC)

## Como Executar

1. Baixe e extraia o arquivo `.zip` com os projetos
2. Consulte o `README.md` da pasta do mini-projeto para os passos específicos
3. Compile e execute a classe que possui a função `main`

## Projetos

- `01-java-exercicios-basicos`: exercícios introdutórios de Java com entrada/saída, laços e operações básicas
- `02-classes-objetos`: prática de classes e objetos com cadastro simples de aluno
- `03-poo-heranca`: exemplo de herança entre classes de animais com execução no zoológico
- `04-libgdx-chuvagamer`: jogo 2D com LibGDX para coletar gotas de chuva com um balde
- `05-poo-interface-polimorfismo`: uso de interfaces e polimorfismo para cálculo de tributos
- `06-substituicao-palavras-arquivo`: busca e substituição de palavras em arquivos de texto
- `07-libgdx-chuvagame-com-save`: versão do jogo de chuva com persistência de progresso
- `08-gestao-contas-bancarias`: sistema de contas bancárias com tipos diferentes e leitura de CSV
- `09-conexao-banco-de-dados`: conexão JDBC com MySQL e leitura de dados relacionais
- `10-java-swing`: aplicações desktop com Swing, incluindo jogo de adivinhação
- `11-java-swing-crud-arquivo`: CRUD em interface Swing com persistência em arquivo CSV
- `12-libgdx-chuvagame-polimorfismo`: jogo LibGDX com objetos diferentes usando polimorfismo
- `13-poo-polimorfismo`: demonstração de polimorfismo com diferentes mamíferos em coleção
- `14-gestao-biblioteca`: gestão de publicações com herança, CSV e interface gráfica
- `15-tratamento-excecoes`: exemplos de exceções personalizadas e tratamento de erros
- `16-coletor-lixo-java`: jogo LibGDX com monitoramento de memória e coletor de lixo da JVM
- `17-java-rmi-chat`: chat cliente-servidor distribuído com Java RMI
- `18-java-rmi-cadastro-pessoas`: cadastro remoto de pessoas com RMI e persistência em CSV
- `19-singleton`: aplicação de padrão Singleton em contexto de jogo simples
- `20-proxy`: implementação do padrão Proxy para acesso a dados de pessoas
- `21-dao-pessoa-jdbc`: padrão DAO com JDBC para operações de pessoa no MySQL
- `22-dao-pessoa-arquivo-swing`: DAO com arquivo CSV e interface Swing para cadastro
- `23-padrao-mvc`: organização de aplicação em camadas Model-View-Controller
- `24-poo-heranca-veiculos`: herança de classes de veículos com testes de comportamento
- `25-java-swing-crud-jdbc`: CRUD Swing integrado ao banco de dados com JDBC
- `26-java-rmi-jogo-da-forca`: jogo da forca distribuído entre cliente e servidor RMI
- `27-gestao-notas-alunos-padroes-projeto`: gestão de notas com DAO, Proxy, Singleton e JDBC
