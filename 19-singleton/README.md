# Singleton

Projeto para praticar o padrão Singleton em um cenário de jogo simples com interface gráfica.

## Objetivos

- Aplicar o padrão Singleton para instância única
- Integrar padrão de projeto com aplicação visual

## Funcionalidades

- Garantir instância única da classe principal de jogo
- Executar janela com elementos gráficos em tempo de execução
- Disponibilizar classe de teste para validar comportamento singleton

## Tecnologias usadas

- Java
- Java Swing
- Padrão de Projeto Singleton
- VS Code

## Como executar

1. Baixe o repositório em formato zip
2. Extraia o zip em uma pasta local
3. Abra a pasta 19-singleton no terminal ou IDE
4. Compile os arquivos Java:

```bash
javac *.java
```

5. Execute o jogo:

```bash
java Jogo
```

6. Para testar a implementação do padrão, execute também:

```bash
java TestadorDeClasse
```
