# Exercícios Básicos de Java

Conjunto de atividades introdutórias para praticar fundamentos da linguagem Java.

## Objetivos

- Praticar entrada e saída de dados no console
- Trabalhar com estruturas de repetição e vetores
- Aplicar operações matemáticas e manipulação de caracteres

## Funcionalidades

- Decompor um número em posições de vetor
- Exibir tabela com número, quadrado e cubo
- Converter caracteres para seus valores numéricos
- Executar exercícios independentes em classes separadas

## Tecnologias Usadas

- Java
- VS Code

## Como Executar

1. Baixe e extraia o arquivo `.zip` do repositório
2. Abra a pasta `01-java-exercicios-basicos` no terminal ou IDE
3. Compile o arquivo desejado, por exemplo:

```bash
javac Atividade1a.java
```

4. Execute a classe compilada, por exemplo:

```bash
java Atividade1a
```

5. Repita para Atividade1b, Atividade1c e Atividade1d conforme necessário
