# Proxy

Projeto de cadastro de pessoas aplicando o padrão Proxy para controlar acesso aos dados.

## Objetivos

- Praticar o padrão de projeto Proxy
- Trabalhar leitura de dados em arquivo CSV

## Funcionalidades

- Carregar registros de pessoas a partir do arquivo pessoal.csv
- Encapsular operações de acesso por uma camada intermediária
- Executar operações de consulta pelo programa principal

## Tecnologias Usadas

- Java
- Padrão de Projeto Proxy
- VS Code

## Como Executar

1. Baixe e extraia o arquivo `.zip` do repositório
2. Abra a pasta `20-proxy` no terminal ou IDE
3. Compile o arquivo principal:

```bash
javac Main.java
```

4. Execute o programa:

```bash
java Main
```
