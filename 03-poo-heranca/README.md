# POO com Herança

Projeto para demonstrar herança entre classes de animais e comportamento polimórfico.

## Objetivos

- Aplicar herança entre classes base e derivadas
- Praticar sobrescrita de métodos
- Demonstrar o uso de polimorfismo

## Funcionalidades

- Definir classe base Animal e classe intermediária Mamifero
- Implementar subclasses como Cachorro e Vaca
- Executar simulação em Zoologico com sons e comportamentos

## Tecnologias usadas

- Java

## Como executar

1. Baixe o repositório em formato zip
2. Extraia o zip em uma pasta local
3. Abra a pasta 03-poo-heranca no terminal ou IDE
4. Compile os arquivos Java:

```bash
javac *.java
```

5. Execute a classe principal:

```bash
java Zoologico
```
