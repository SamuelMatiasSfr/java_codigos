# POO com Interface e Polimorfismo

Projeto que aplica interfaces para cálculo de tributos em diferentes tipos de objetos.

## Objetivos

- Praticar criação e implementação de interfaces
- Aplicar polimorfismo em coleções de objetos

## Funcionalidades

- Definir interface tributável com contrato de cálculo
- Calcular tributos de diferentes entidades
- Acumular total de impostos em um gerenciador

## Tecnologias Usadas

- Java
- VS Code

## Como Executar

1. Baixe e extraia o arquivo `.zip` do repositório
2. Abra a pasta `05-poo-interface-polimorfismo` no terminal ou IDE
3. Compile os arquivos Java:

```bash
javac *.java
```

4. Execute a classe de teste:

```bash
java TestaGerenciador
```
