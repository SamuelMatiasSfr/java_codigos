# POO com Interface e Polimorfismo

Projeto que aplica interfaces para cálculo de tributos em diferentes tipos de objetos.

## Objetivos

- Praticar criação e implementação de interfaces
- Aplicar polimorfismo em coleções de objetos

## Funcionalidades

- Define interface tributável com contrato de cálculo
- Calcula tributos de diferentes entidades
- Acumula total de impostos em um gerenciador

## Tecnologias usadas

- Java

## Como executar

1. Baixe o repositório em formato zip
2. Extraia o zip em uma pasta local
3. Abra a pasta 05-poo-interface-polimorfismo no terminal ou IDE
4. Compile os arquivos Java:

```bash
javac *.java
```

5. Execute a classe de teste:

```bash
java TestaGerenciador
```
