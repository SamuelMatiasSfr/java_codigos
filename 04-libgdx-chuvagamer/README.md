# LibGDX Chuva Game

Jogo 2D desenvolvido com LibGDX em que o jogador movimenta um balde para coletar gotas.

## Objetivos

- Praticar desenvolvimento de jogos 2D com LibGDX
- Trabalhar com sprites, sons e loop de jogo
- Integrar entrada do usuário com atualização de cena

## Funcionalidades

- Mover o balde com entrada do usuário
- Gerar gotas em posições aleatórias
- Detectar colisões e atualizar pontuação
- Reproduzir áudio de fundo e efeitos sonoros

## Tecnologias Usadas

- Java
- LibGDX
- VS Code

## Como Executar

1. Baixe e extraia o arquivo `.zip` do repositório
2. Abra a pasta `04-libgdx-chuvagamer` em uma IDE 
3. Garanta que as bibliotecas da pasta libs estejam configuradas no classpath do projeto
4. Execute a classe `DesktopStarter.java` no caminho `src/com/gpjecc/blogspot/chuvagame`
